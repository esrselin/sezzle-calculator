# AI Usage

AI tools were used as a development assistant during the implementation, mainly for debugging, test coverage, code review, and documentation.

## Prompts Used

- "I have a Go calculator with a REST endpoint. What should I test for the calculation logic?"
- "Can you check these Go tests and point out anything missing or incorrect?"
- "The division by zero test is failing. Here is my current code and test output."
- "What are some useful API handler tests for this calculator?"
- "I added square root support. What edge cases should I cover?"
- "The calculator works for the basic operations. What edge cases should I check before moving on?"
- "Vitest is installed but npm test is not working. Here is my current Vite config and the error."
- "This test fails with 'expect is not defined'. What is wrong with my Vitest setup?"
- "The frontend tests are passing. What should I check before considering the testing complete?"
- "The coverage is around 77%. Is that reasonable for this assignment, or are there meaningful tests I should add?"
- "Review the current frontend styling for a small calculator assignment. Keep it simple and responsive."
- "Review the project against the assignment requirements and list what is still missing."
- "What should be included in the README for this assignment?"

## How AI Was Used

AI assistance was used for:

- Exploring implementation approaches
- Identifying edge cases
- Writing and reviewing tests
- Debugging errors
- Reviewing code structure
- Reviewing frontend styling
- Improving documentation

The implementation was reviewed and tested manually, including running the backend and frontend test suites and verifying the production build.
